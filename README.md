## 系統核心特色

1. **五大教學模組結構化整理 (T01 ~ T05)**
   - **T01 課綱比較分析**：跨校個體經濟學課綱橫向比對、教學法/進度/評量對比表與 Word 產出。
   - **T02 教學計畫與健檢**：18 週進度表自動生成、核心能力矩陣對應（C1-C4）與 AI 邏輯合規健檢。
   - **T03 講義精煉轉簡報**：長篇講義重組為 8 頁對比色彩投影片、排版規範與 50 分鐘時長講者備忘稿。
   - **T04 Gmail 智慧收發排程**：廣告信/帳單/公務三層分類、平日自動定時排程、防呆批次刪除與訂閱退訂彙整。
   - **T05 評量分析與試算表**：試題答對率多維度統計、排序長條圖、低於 50% 共同盲點診斷與 Google Sheets 匯出。

2. **多維度視覺化互動控制**
   - **字級調整**：中（標準 16px）、大（18px）、特大（20px），即時放大舒適閱讀。
   - **布景主題**：淺色（Light）、深色（Dark）、草木綠（Green 護眼）、慈大藍（Blue 科技）。
   - **提示詞工作室 (Prompt Playground)**：支援自訂學科、對象、週次與簡報規範，動態生成專屬 Prompt 並一鍵複製。

3. **研習資源安全存取防護**
   - 採用瀏覽器原生 Web Crypto API (`crypto.subtle.digest('SHA-256')`) 進行安全比對。
   - 通行狀態儲存於本地 `localStorage`，並提供右上角鎖頭隨時手動重新上鎖。
